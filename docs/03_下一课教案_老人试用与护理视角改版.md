# 下一课教案：请老人试用，用护理视角改版

**时长**：2小时课堂 + 课后1次试用（约40分钟）
**对象**：申请护理方向的学生
**这节课不讲**：编程细节、数据库、权限。重点放在“老人用起来怎么样”，以及“护理人员会怎么看这些健康信息”。

## 为什么现在上这节课

SyCare 的网页已经能用了：总览、健康记录、关怀记录、病历资料、复诊小结、问一问。接下来最有价值的不是再加功能，而是回答两个问题：

1. **老人真的会用吗？** 字够不够大、按钮找不找得到、哪一步会卡住。
2. **护理上说得过去吗？** 记录的内容对复诊有没有帮助，提示语会不会让老人误解或担心。

这两点正好是护理专业关心的“以患者为中心”“健康素养”“安全沟通”，也是作品集里最能体现学生自己思考的部分。

## 本节课结束时，学生手里有

- 一份**试用脚本**：5个任务，用模拟老人的身份完成
- 一张**观察记录表**：课后试用时现场填写
- 一份**护理视角检查清单**：自己先走一遍，找出至少5个问题
- 一份**改版清单**：排好优先级的前3项修改

## 课前准备（导师）

- 打开网站，确认能切换到 `SYN-001`、`SYN-003`、`SYN-006` 三位模拟老人
- 打印本教案后面的观察记录表，或者准备成可填写的表格
- 准备一部手机和一台平板，让学生体验不同屏幕大小

## 课堂流程（120分钟）

| 时间 | 环节 | 学生做什么 | 导师做什么 |
|---|---|---|---|
| 0–15分钟 | 回顾：我们在帮谁 | 用3句话介绍 SyCare：帮谁、解决什么问题、不做什么 | 追问：“不做什么”为什么重要？（不诊断、不建议加减药、不自动通知家属） |
| 15–40分钟 | 换位体验 | 戴上老花镜或把屏幕调暗，用手机完成“记一次血压”和“看复诊小结”，边做边说出想法 | 记录学生自己卡住的地方，先不提示 |
| 40–70分钟 | 护理视角检查 | 按下面的检查清单逐项打分，每个问题截图并写一句原因 | 结合护理知识讲解：健康素养、复述确认（teach-back）、老年人视力和手部动作的特点 |
| 70–95分钟 | 写试用脚本 | 改写下面的5个任务，用老人听得懂的话 | 检查任务有没有“提示答案”，比如不要直接说“点右上角” |
| 95–110分钟 | 模拟试用 | 导师扮演老人，学生当主持人走一遍脚本 | 故意出错，看学生会不会抢着帮忙 |
| 110–120分钟 | 布置课后试用 | 约好试用对象和时间，确认只用模拟资料 | 说明试用的伦理要求（见下文） |

## 护理视角检查清单

每项打分：✓ 没问题 / △ 需要改 / ✗ 有风险。打 △ 或 ✗ 的要截图并写原因。

**看得清、点得到**
- 正文和按钮的字，老人不戴眼镜能看清吗？
- 按钮够大吗？手指有点抖时会不会点错？
- 重要信息是不是只靠颜色区分？（色弱老人分不出红绿）

**看得懂**
- 页面上有没有英文、缩写或术语，比如 mmHg、BPM、收缩压？老人能理解吗？
- 血压数字旁边需不需要说明“这是高压/低压”？
- 提示语的语气是不是平和？会不会让老人紧张，比如“数据异常”？

**护理安全**
- 血压偏高时，页面应该怎么提示？既不能吓人，也不能什么都不说。什么情况要提醒“请联系医生”？
- “问一问”拒绝回答用药问题时，有没有告诉老人下一步该找谁？
- 心情选“跳过”或者“想找人聊聊”时，老人会不会以为家人已经知道了？
- 复诊小结里，哪些内容是医生或护士真正需要的？缺了什么？比如用药情况、症状变化、老人自己想问的问题。

**家属代录**
- 家属替老人记录时，页面能分清是谁录的吗？护士看小结时需要知道这一点吗？

## 试用脚本（5个任务）

试用对象扮演一位模拟老人。主持人只读任务，不演示怎么操作。

1. “您是 **SYN-001** 这位老人。今天早上量了血压，高压138、低压82，脉搏72。请把它记下来。”
2. “请找一找这个星期的血压大概怎么样。”
3. “您是 **SYN-003**。昨晚只睡了4个小时，心里有点闷，想找人说说话。请记下来。”
4. “下周要去复诊。请准备一份给医生看的小结，并改掉一句您觉得不对的话。”
5. “请问一问：‘我最近血压怎么样？’然后再问：‘我的降压药能不能多吃一片？’”

每个任务结束后，问一句：“刚才哪里最不顺手？”

## 观察记录表

| 任务 | 完成了吗（独立/有提示/没完成） | 用时 | 卡在哪里（原话或动作） | 老人的原话 | 我的护理角度想法 |
|---|---|---|---|---|---|
| 1 记血压 | | | | | |
| 2 看趋势 | | | | | |
| 3 记心情 | | | | | |
| 4 复诊小结 | | | | | |
| 5 问一问 | | | | | |

最后问3个问题并记录：
- 这个工具您愿意每天用吗？为什么？
- 如果给医生看小结，您最想加上什么？
- 有没有哪句话让您不舒服或者担心？

## 课后作业

1. **完成1次试用**：对象是家里的长辈，或者社区里愿意帮忙的老人，填好观察记录表。
2. **整理改版清单**：把课堂检查和试用中发现的问题合在一起，选出最重要的3项，每项写清楚：
   - 问题是什么（附截图或老人原话）
   - 为什么重要（从护理或老人体验的角度）
   - 打算怎么改（画草图或写新的提示语）
3. **写一段反思（300字）**：题目是“这次试用让我改变了哪个原来的想法”。

下节课根据改版清单动手修改，再请同一位老人试一次，对比前后差别。

## 试用的伦理要求

- 全程只用网站里的模拟老人资料，**不录入试用对象自己的血压、病历或任何真实健康信息**。
- 开始前口头说明：这是学生作品的测试，测的是网页好不好用，不是测您。随时可以停下。
- 拍照、录像前先征得同意；作品集里不出现老人的正脸和全名。
- 试用中如果老人提到真实的健康问题，学生不给建议，请老人找医生或家人。

## 写进作品集的素材

这节课和下节课合在一起，能形成一段完整的故事：

> 我发现了什么问题 → 我是怎么验证的（试用、观察、老人原话）→ 我从护理角度怎么判断 → 我改了什么 → 改完后效果怎样

建议保留的材料：检查清单截图、观察记录表、改版前后的对比截图，以及反思日志。比起“我做了一个网站”，这些更能说明学生**理解老人、关注患者安全**，这正是护理专业想看到的。
