# SyCare 学生入门：注册账号并打开项目

导师已经建好 [GitHub 仓库](https://github.com/dylanmiao7/SyCare) 和 Supabase 的 SyCare 项目，准备材料已经合并到 `main`。你不需要重新创建仓库、Supabase 组织或数据库项目。本手册只做课前准备；网页和数据库功能会在课上开发。

## 1. 注册三个账号

| 平台 | 你要做什么 | 完成标志 |
|---|---|---|
| [GitHub](https://github.com/signup) | 用自己的邮箱注册、验证邮箱，按提示设置双重验证；把**用户名**发给导师 | 接受导师发来的 SyCare 仓库协作邀请 |
| [Supabase](https://supabase.com/dashboard) | 注册后接受导师发来的组织邀请 | 登录后能看到导师已有的 **SyCare** 项目 |
| [DeepSeek 开放平台](https://platform.deepseek.com/) | 注册 API 开放平台；和导师确认测试额度及是否现在创建自己的 API key | 能登录开放平台；如已创建 key，私下妥善保存 |

三个平台都用你自己的账号。密码、双重验证恢复码、数据库密码和 API key 不要发给导师或放进 GitHub。付费或充值由学生与监护人、导师先商量；课前不要求购买任何服务。

如果邀请没收到，先核对登录的账号和邮箱，再请导师检查邀请状态。公开仓库可以阅读，但向仓库提交修改仍需接受协作邀请。

## 2. 用 coding 工具把仓库放到电脑上

选择你已经在用的一款 coding 工具，例如 Codex、Claude Code 或 WorkBuddy，打开它的**本地 coding 模式**，把下面这段话发给它：

> 请帮我把 `https://github.com/dylanmiao7/SyCare.git` 克隆到我电脑上选定的文件夹。若还没安装 Git 或连接 GitHub，请一步步指导我完成。完成后确认这是导师的仓库、当前在最新的 `main` 分支，并告诉我项目文件夹在哪里。现在不要修改、提交或推送任何文件。

工具如果弹出安装 Git、浏览器登录或授权提示，按实际界面完成；如果没有提示，就直接问它“下一步怎样安装 Git 并登录 GitHub”。不必为了这一步另装 GitHub Desktop，也不要下载 ZIP 或新建同名仓库。

打开克隆后的文件夹，确认能看到 `README.md`、`docs/01_20小时开发流程.md` 和 `data/README.md`。目前还没有可运行的前端，暂时不需要安装 npm 依赖。

## 3. 第一次协作提交留到课上

有了真正的页面或功能修改后，请 coding 工具先从最新 `main` 建立自己的工作分支。让它展示改动，再由你确认提交和推送，最后向 `main` 发 Pull Request 给导师检查。不要把密码、API key、真实病历、临时预览或导出文件提交到仓库，也不要直接推送到 `main`。

如果工具要求你确认 GitHub 授权、提交内容或远程地址，先看清楚再继续；遇到冲突时和导师一起处理，不使用强制推送。

## 课前告诉导师

- GitHub 用户名，以及仓库邀请是否已接受。
- Supabase 账号是否能看到 SyCare 项目。
- DeepSeek 开放平台是否已注册；API key 和额度准备到哪一步，**不要发送 key 本身**。
- 仓库是否已克隆到本地；若失败，告诉导师卡在安装 Git、登录还是克隆。

开发阶段只使用 `data/` 中的模拟数据。真实健康资料和密钥不要放进公开仓库。
