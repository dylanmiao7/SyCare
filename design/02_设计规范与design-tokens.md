# 02 · 设计规范与 design tokens

> 本文件是**唯一的样式真相来源**。原型 `design/prototype/assets/tokens.css` 必须与本文件一致。
> 所有对比度数值都是实测值（WCAG 2.1 相对亮度公式），不是估计。

---

## 1. 字体与字号

### 字体栈（不加载 Web 字体）

```css
--font-sans: -apple-system, "PingFang SC", "Hiragino Sans GB",
             "Microsoft YaHei", "Noto Sans CJK SC", "Source Han Sans SC",
             system-ui, sans-serif;
```

**为什么不用思源黑体等中文字体包**：一个中文字体子集动辄 2—5 MB，老年用户手机流量与加载速度代价太高，且系统自带的苹方/微软雅黑已经足够清晰。

### 字号阶梯

根字号设为 **20px**，全站用 `rem`，用户在「设置」里切换字号时**只改根字号**，所有元素等比放大。

| Token | 计算值 | 用途 |
|---|---:|---|
| `--fs-root` | `20px` | 根字号（设置页可切 20 / 22 / 24px） |
| `--fs-hero` | `2rem` = 40px | 首页问候语、问答页标题 |
| `--fs-h1` | `1.75rem` = 35px | 页面大标题 |
| `--fs-h2` | `1.4rem` = 28px | 区块标题 |
| `--fs-h3` | `1.2rem` = 24px | 卡片标题（首页入口标题） |
| `--fs-lg` | `1.15rem` = 23px | 数值显示（血压读数） |
| `--fs-body` | `1rem` = 20px | **正文最小值，不再往下** |
| `--fs-sm` | `0.9rem` = 18px | 徽标、次要说明 |
| `--fs-xs` | `0.8rem` = 16px | **仅限徽标内文字**，一律不用于句子 |

> **红线**：任何成句的中文不得小于 `--fs-body`（20px）。`--fs-xs` 只能出现在徽标（如「未记录」）这种 2—4 字的标签里。

### 行高与字重

```css
--lh-tight: 1.35;   /* 标题 */
--lh-body:  1.7;    /* 正文，中文需要更大行距 */
--lh-badge: 1.2;    /* 徽标 */
--fw-normal: 400;
--fw-medium: 500;   /* 用于强调，不用 700 —— 中文粗体在小字号下发糊 */
--fw-bold:   600;   /* 仅标题与按钮 */
```

## 2. 颜色

### 语义色（全部实测对比度）

| Token | 色值 | 用途 | 对比度（实测） |
|---|---|---|---|
| `--c-bg` | `#F5F6F4` | 页面底色（微暖灰，比纯白柔和） | — |
| `--c-surface` | `#FFFFFF` | 卡片、输入框 | — |
| `--c-ink` | `#111827` | 正文、标题 | 16.36:1 on `--c-bg` ✅AAA |
| `--c-ink-muted` | `#4B5563` | 次要说明文字 | 6.97:1 on `--c-bg` ✅AA |
| `--c-ink-subtle` | `#6B7280` | 弱化文字 | 4.83:1 on 白 ✅AA |
| `--c-primary` | `#14509B` | 主色、按钮、链接、图表主线 | 7.92:1 on 白 ✅AAA |
| `--c-primary-hover` | `#0F3C74` | 按下态 | — |
| `--c-border` | `#6B7280` | 输入框边框（必须可见） | 4.83:1 on 白 ✅ |
| `--c-border-soft` | `#D1D5DB` | 卡片分隔线（纯装饰） | — |

### 状态色

| 状态 | 文字色 | 底色 | 对比度 | 场景 |
|---|---|---|---|---|
| 成功 / 已记好 | `#0F5132` | `#DCF2E4` | 7.96:1 ✅AAA | 保存成功、`recorded` |
| 注意 / 设备错误 | `#8A5300` | `#FFF8E1` | 5.96:1 ✅AA | `device_error` |
| 危险 / 失败 | `#B3261E` | `#FDECEA` | 5.72:1 ✅AA | 保存失败、上传失败 |
| 中性 / 未记录 | `--c-ink-muted` | `#F3F4F6` | 6.97:1 ✅AA | `not_recorded`、`跳过` |
| 提示 / 信息 | `--c-ink` | `#E7F0FB` | 15.42:1 ✅AAA | 演示免责说明、内存提示 |

> **禁用态例外说明**：`--c-ink-subtle` on `#E5E7EB` 实测 3.90:1，低于正文 4.5:1 门槛。这是 WCAG 明确豁免的禁用控件情形（1.4.3 例外），**但仍禁止用禁用态承载任何必要信息**。

### 心情四色（`mood_response`）

设计上**不做红绿灯**。心情不是测量值，用交通灯语义会让老人觉得「一般」就是有问题。

| 值 | 图标 | 文字色 | 底色 | 说明 |
|---|---|---|---|---|
| `很好` | 😊 | `#0F5132` | `#DCF2E4` | |
| `一般` | 😐 | `#8A5300` | `#FFF8E1` | 与「设备错误」同色系但不共用组件 |
| `不太好` | 😟 | `#B3261E` | `#FDECEA` | 只陈述，不弹出任何建议 |
| `跳过` | — | `--c-ink-muted` | `#F3F4F6` | 文案「这次没回答」，**绝不显示为「不太好」** |

### 图表配色（图形元素 3:1 门槛）

| 元素 | 色值 | 对比度 | 备注 |
|---|---|---|---|
| 血压主线 | `--c-primary` `#14509B` | 7.92:1 ✅ | 同时用**实心圆点**区分于脉搏 |
| 脉搏线 | `#6B7280` | 4.83:1 ✅ | 灰色 + **方点**，形状与颜色双重区分 |
| 睡眠线 | `#0F5132` | 8.6:1 ✅ | |

## 3. 间距、圆角、阴影

```css
--sp-1: 4px;   --sp-2: 8px;   --sp-3: 12px;  --sp-4: 16px;
--sp-5: 20px;  --sp-6: 24px;  --sp-8: 32px;  --sp-10: 40px; --sp-12: 48px;

--r-sm: 8px;    --r-md: 12px;   --r-lg: 16px;   --r-pill: 999px;

--shadow-card: 0 1px 2px rgba(17,24,39,.06);
--shadow-raise: 0 2px 8px rgba(17,24,39,.10);
```

**规则**：卡片之间间距 ≥ `--sp-4`（16px）；表单两行之间 ≥ `--sp-5`（20px）；页面左右留白 ≥ 20px（老人手指粗，贴边容易误触）。

## 4. 触控尺寸

| 元素 | 最小高度 | 说明 |
|---|---:|---|
| 首页入口卡片 | **96px** | 图标 40px + 两行文字 |
| 主按钮 | **64px** | 「保存」「上传」 |
| 次按钮 | **56px** | 「取消」「重试」 |
| 输入框 / 选择器 | **60px** | 手指点进去要稳 |
| 心情四选一按钮 | **72px** | 带 emoji + 文字 |
| 复选框/单选项整体可点区域 | **56px** | 点标签也能选中 |
| 日期选择 | **60px** | 用原生 `<input type="date">` |

**点击区域不得小于 48×48px**（WCAG 2.5.5），本项目所有交互元素都超过该值。

## 5. 焦点与键盘

```css
:focus-visible {
  outline: 3px solid #14509B;
  outline-offset: 3px;
  border-radius: var(--r-sm);
}
```

- 焦点环对比度 7.92:1，**禁止 `outline: none` 而不给替代样式**。
- Tab 顺序 = 视觉顺序（首页 5 个入口自上而下）。
- 提供「跳到主要内容」链接（`#main`），键盘首次 Tab 时可见。

## 6. 病历语义徽标（ClinicalNotation）

这是本项目**最关键的视觉约定**。三种「没有数字」的情况必须一眼可分。

| 徽标 | 文字 | 底色 | 文字色 | 图标 | 语义 |
|---|---|---|---|---|---|
| `--` | `—` | 透明 | `--c-ink-subtle` | — | 数值位置占位，永远不显示 `0` |
| 未记录 | `未记录` | `#F3F4F6` | `--c-ink-muted` | `○` 空心圆 | `capture_status = not_recorded`：当时没量 |
| 设备错误 | `设备错误` | `#FFF8E1` | `#8A5300` | `⚠` | `capture_status = device_error`：设备没测出来 |
| 跳过 | `这次没回答` | `#F3F4F6` | `--c-ink-muted` | `○` 空心圆 | `mood_response = 跳过`：本人没回答 |
| 本人记录 | `本人记录` | 透明 | `--c-ink-muted` | — | `recorded_by_type = self` |
| 家属代录 | `家属代录` | `#E7F0FB` | `--c-primary` | — | `recorded_by_type = family` |
| 已确认 | `已确认` | `#DCF2E4` | `#0F5132` | `✓` | `text_status = confirmed_demo`，可供问答引用 |
| 未确认 | `未确认` | `#FFF8E1` | `#8A5300` | `⚠` | 图片文字未经人确认，**不可供问答引用** |

### 使用规则

1. **颜色 + 图标 + 文字三重编码**，色盲用户仅靠形状和文字也能区分（WCAG 1.4.1）。
2. 「未记录」与「设备错误」**必须不同底色**，因为后续动作不同：前者是「补量一下」，后者是「检查设备」。
3. 「跳过」**不得**使用 `--c-danger` 或 `--c-warn` 任何一色。
4. 徽标文字用 `--fs-xs`（16px）是允许的例外；但**同一屏内必须有一句 20px 的正常文字解释它代表什么**。

## 7. 响应式

| 断点 | 布局 |
|---|---|
| `< 480px`（手机，主要目标） | 单列，页面留白 20px，卡片全宽 |
| `480—760px` | 单列，最大宽度 640px 居中 |
| `> 760px`（桌面/投屏演示） | 单列，**最大宽度锁定 720px 居中** |

> **为什么桌面不放大成多列**：这是给老人用的手机工具，桌面上唯一场景是老师投屏演示。锁定 720px 可以保证演示时字够大、行宽不超过 40 个中文字（超过会串行）。

- 尊重系统字号设置：不写 `user-scalable=no`，不禁用缩放。
- 无横向滚动：`overflow-x: hidden` 不允许出现在正文容器上，靠布局本身保证。
- 支持横屏：横屏时不改变字号，只增加垂直空间。
