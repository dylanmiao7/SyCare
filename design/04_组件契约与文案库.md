## 1. 组件清单

### 1.1 基础组件 `ui/`

| 组件 | 职责 | 关键属性 | 状态 | 无障碍要求 |
|---|---|---|---|---|
| `AppShell` | 顶栏 + 返回 + 标题 + 字号按钮 + 演示横幅 | `title`, `backTo`, `children` | — | `<header>` + `<main id="main">`；「跳到主要内容」为首个可聚焦元素 |
| `SkipLink` | 跳到主要内容 | — | 聚焦时可见 | 必须存在 |
| `BigButton` | 全宽大按钮 | `variant: primary\|secondary\|danger`, `size: 64\|56`, `loading`, `disabled` | 默认/按下/加载/禁用 | `aria-busy` for loading；禁用不承载必要信息 |
| `IconButton` | 图标按钮 | `label`(必填，作 `aria-label`), `icon` | — | 必须带 `label`；点击区 ≥48px |
| `TextField` | 文本/数字输入 | `label`, `hint`, `unit`, `inputmode`, `error`, `required` | 默认/聚焦/错误/禁用 | `<label for>` 绑定；`error` 用 `aria-describedby` + `aria-invalid` |
| `DateField` | 日期 | `value`, `max`, `min`, `error` | 同上 | 原生 `type=date`；不自定义日期选择器 |
| `NumberField` | 带单位的数字 | 同 `TextField` + `unit` | 同上 | `inputmode="numeric"` / `"decimal"` |
| `SegmentedControl` | 分段切换（血压/脉搏/睡眠；小/标准/大） | `options`, `value`, `onChange` | 默认/选中 | `role="radiogroup"` + 方向键；选中项 `aria-checked` |

| `Alert` | 提示条 | `tone: ok\|warn\|danger\|info\|neutral`, `title`, `icon`, `action` | — | `role="status"`（普通）/ `role="alert"`（错误）；图标 + 文字双编码 |
| `InlineError` | 字段级错误 | `children` | — | 与字段用 `aria-describedby` 关联 |
| `EmptyState` | 空列表 | `illustration`, `title`, `description`, `action` | — | 有可操作按钮，不留死路 |
| `Loading` | 加载 | `label`（必须有中文文字，不能只有转圈） | — | `role="status"` + `aria-live="polite"` |

### 1.2 业务组件 `domain/`

| 组件 | 职责 | 关键属性 | 说明 |
|---|---|---|---|
| **`ClinicalBadge`** | 病历语义徽标（**本项目核心组件**） | `kind: 'not_recorded'\|'device_error'\|'skipped'\|'self'\|'family'\|'confirmed'\|'unconfirmed'\|'unreadable'` | 唯一渲染 `.badge` 的地方；文案与配色见 [02 §6](02_设计规范与design-tokens.md)。**禁止**在别处手写徽标 |
| `MissingValue` | 数值占位 | `kind`, `unit?` | 渲染 `—` + `ClinicalBadge`；任何空数值**必须**走此组件，禁止直接输出 `0` 或空串 |
| `EntryCard` | 首页五个入口 | `emoji/icon`, `title`, `desc`, `href` | 高 96px，整卡可点，右侧 `›` |
| `TodayStatusBar` | 首页今日状态条 | `state: 'done'\|'none'\|'device_error'`, `detail` | 整条可点 → `#/checkin` |
| `MetricChart` | 折线图（血压/脉搏/睡眠） | `series`, `unit`, `referenceBand?`, `threshold?`, `missingDates`, `onPointTap` | 纯 SVG；断线处理缺失；含 `sr-only` 数据表 |
| `ChartLegend` | 图例 | `items: {shape,color,label}[]` | 形状 + 颜色双编码 |
| `StatLine` | 统计句 | `recordedDays`, `missingDays`, `deviceErrorDays` | 强制同时展示「已记录」与「未记录」 |
| `DayRecordRow` | 记录列表一行 | `record`, `onOpen` | 含记录人徽标；缺失走 `MissingValue` |
| `RecordDetailSheet` | 底部详情弹层 | `record`, `onClose` | 焦点陷阱 + Esc 关闭 + 关闭后焦点回到触发元素 |
| `UploadDropzone` | 上传区 | `accept`, `maxSize`, `onPick` | `<input type=file>` 可聚焦；点击区 ≥160px |
| `FileCard` | 文件条目 | `file`, `status`, `onOpen`, `onDelete` | `status` 驱动 `ClinicalBadge`；`未确认` 必须可见 |
| `MemoryNotice` | 内存存储提示 | `scope` | **存病历页必须常驻**；文案见文案库 |
| `ConfirmDialog` | 二次确认 | `title`, `body`, `confirmText`, `cancelText`, `tone` | 不用原生 `confirm()`；焦点陷阱 |
| `SourceList` | 出处列表 | `sources: {label, count, range, refId}[]` | 每条可点回来源页；供「复诊小结」「问一问」共用 |
| `SummaryPreview` | 小结正文 | `text`, `editable`, `onChange` | 打印样式；`white-space: pre-wrap` |
| `MissingInfoList` | 缺失信息清单 | `items: string[]` | 复诊小结必备 |
| `ChatBubble` | 对话气泡 | `role: 'user'\|'assistant'`, `tone`, `sources`, `disclaimer` | 四种回答类型靠 `tone` 区分 |
| `SuggestionChips` | 建议问题 | `questions`, `onPick` | ≥56px 高 |
| `PrivacyNotice` | 分享偏好提示 | `preference`, `supportPerson` | SYN-006 场景必须显示 |

### 1.3 组件依赖规则

1. `ClinicalBadge` 是**唯一**徽标实现，其余组件不得自带徽标样式。
2. `MissingValue` 是**唯一**允许渲染 `—` 的组件。
3. 任何显示数值的地方必须能回答「这个值是记的，还是没记？」——因此 `MissingValue` 与数值展示成对出现。
4. `ui/` 不依赖 `domain/`；`domain/` 可用 `ui/`。

## 3. 文案写作规则

| 规则 | 正确 | 错误 |
|---|---|---|
| 用「您」，不用「你」 | `请填一下高压` | `请输入收缩压` |
| 说人话 | `高压` `低压` | `收缩压` `舒张压` `SBP` |
| 不用感叹号 | `记好了` | `保存成功！` |
| 不指责用户 | `今天还没记` | `您已漏记 2 天` |
| 提到缺失要说原因 | `血压计没测出来` | `数据异常` |
| 不承诺医疗效果 | `记下来给医生看` | `帮您控制血压` |
| 免责句固定措辞 | `不是医生诊断` | `仅供参考` |
| 数字带单位与天数 | `28 天里平均 140` | `平均值 140` |
| 不用「必须/禁止」对用户说话 | `可以再量一次` | `必须重新测量` |
| 跳过用中性词 | `这次没回答` | `未填写` `已跳过` |
